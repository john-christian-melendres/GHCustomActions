## Project Overview

A monorepo of 5 reusable GitHub Actions written in TypeScript, plus a composite semantic-release action. Each action lives in its own directory with an `action.yml` and `index.ts`, sharing a single root `package.json`.

## Commands

```bash
npm run all              # Full pipeline: format → lint → test → coverage → package all actions
npm run bundle           # Format and package (shortcut for dev loop)
npm run package          # Build only the root action (ncc → dist/index.js)
npm run package:<name>   # Build a specific action (e.g. package:deployed-task-log)
npm test                 # Run Jest tests
npm run coverage         # Generate coverage badge to badges/coverage.svg
npm run lint             # ESLint only
npm run format:write     # Prettier (write mode)
npm run format:check     # Prettier (check mode, no writes)
script/release           # Interactive bash script to tag and push a release
```

To build a single action after editing it:

```bash
npm run package:deployed-task-log
npm run package:update-repository-variable
npm run package:update-environment-variable
npm run package:save-log-to-json
npm run package:parse-json
```

## Architecture

Each action follows the same pattern:
- **`<action>/action.yml`** — declares inputs, outputs, and entry point (`node20`, `dist/index.js`)
- **`<action>/index.ts`** — all logic; uses `@actions/core` for inputs/outputs and `@actions/exec` or `@octokit/rest` for side effects
- **`<action>/dist/index.js`** — bundled output (committed); generated by `ncc build`

The `dist/index.js` files are committed and must be rebuilt whenever `index.ts` changes.

### Actions

| Action | Purpose |
|--------|---------|
| `deployed-task-log` | Runs `git log` between a commit hash and HEAD, emits structured commit info with PR URL detection |
| `update-repository-variable` | PATCH `/repos/{owner}/{repo}/actions/variables/{name}` via Octokit |
| `update-environment-variable` | Same as above but for environment-scoped variables |
| `save-log-to-json` | Reads/creates `log.json`, merges new data (spread), writes back |
| `parse-json` | Parses JSON input, formats keys to title-case, emits newline-delimited `Key: value` text |
| `semantic-release` | Composite action: downloads configs from main branch, runs `npx semantic-release` |

### Key conventions

- TypeScript target `ES2022`, module system `NodeNext`
- Prettier: no semicolons, single quotes, 80-char width, LF line endings
- ESLint config is at `.github/linters/.eslintrc.yml`
- Jest preset: `ts-jest`; test files match `**/*.test.ts`; coverage source is `./src/**`
- `@octokit/rest` v20 is pinned — authenticate with a token passed as action input, not env var
